# 西村OS 受付窓口のつくり方（1回だけ・約10分）

これをやると：
- 西村OSの初期設定が **「URL＋合言葉」の2つだけ** になる（14個のCSV URLは不要）
- 西村OSの **＋ボタン** から、体重・食事の写真・メモを直接スプシに記録できる（Claudeとの会話ゼロ）
- **体重計に乗るだけ** で、iPhoneのヘルスケア経由で毎朝自動記録される

---

## ステップ1：スプシに窓口を貼る（5分）

1. Googleスプシ「西村家ファイナンスDB_v2」を開く（個人アカウント nishiga8）
2. メニュー **拡張機能 → Apps Script**
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの [`Code.gs`](Code.gs) の中身を丸ごと貼る → 💾保存
4. 左の ⚙ **プロジェクトの設定** → 一番下 **スクリプト プロパティ** → 「プロパティを追加」
   - `KEY` ＝ 好きな合言葉（例: `pengin-2026-xxxx`。推測されにくいもの）
   - `ANTHROPIC_API_KEY` ＝ 写真の自動読み取りを使うなら、Claude APIキー（無くても写真の保存・体重・メモは動く）
5. エディタに戻り、上の関数選択で **`selfCheck`** を選んで ▶実行
   - 初回は「承認が必要」→ 自分のアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→ 許可
   - 下のログに ✅ が並べばOK。— のシート名が実際と違う場合は、`Code.gs` 上部の `SHEETS` を実際のシート名に直す

## ステップ2：ウェブアプリとして公開（2分）

1. 右上 **デプロイ → 新しいデプロイ** → 種類の歯車 ⚙ →「ウェブアプリ」
2. 設定：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉が無いと何も返さないので大丈夫）
3. **デプロイ** → 出てきた **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> コードを直したら「デプロイを管理 → ✏️編集 → バージョン：新バージョン → デプロイ」でURLはそのまま更新される。

## ステップ3：西村OSに入れる（1分）

1. 西村OSを開く →（初期設定画面が出なければ ⚙設定）
2. ① 受付窓口URL ② 合言葉 を入れて **起動**
3. **🔗 復元リンクをコピー** → 自分宛てのLINEかメモに貼って保存
   - 今後、設定が消えても・iPhoneを替えても **このリンクを開くだけで元どおり**

## ステップ4：体重を全自動にする（iPhone・3分）

ショートカットアプリで：

1. **オートメーション** タブ → ＋ →「時刻」→ 毎日 8:00（体重を測った後の時間）→「すぐに実行」→ 次へ
2. 「新規の空のショートカット」→ 以下のアクションを順に追加：
   1. **ヘルスケアサンプルを検索**：種類「体重」、並び順「開始日 最新順」、制限「1」
   2. **URLの内容を取得**：
      - URL：ステップ2のウェブアプリURL
      - 方法：**POST**
      - 本文を要求：**JSON**
        - `key` ＝（合言葉）
        - `type` ＝ `weight`
        - `kg` ＝（変数：ヘルスケアサンプル → 値）
        - `date` ＝（変数：ヘルスケアサンプル → 開始日）
        - `source` ＝ `ヘルスケア`
3. 完了。同じ日・同じ体重は二重登録されないので、何回動いても大丈夫

## よくある質問

- **お金はかかる？** 体重・メモ・写真の保存は0円（Googleの無料枠）。写真のカロリー読み取りだけClaude APIを使い、**1枚ずつ使い捨て**で読むので1枚あたり数円程度。会話が溜まって重くなることはない
- **写真はどこに？** Googleドライブの「西村OS写真」フォルダ
- **「その他」の写真やメモは？** スプシの「受信箱」シートに溜まる。整理したいときだけClaudeに「受信箱整理して」
- **CSVの「ウェブに公開」はもう要らない？** 窓口で動くのを確認したら、スプシの「ファイル → 共有 → ウェブに公開 → 公開を停止」でOK（そのほうが安全）
